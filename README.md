## ✨ 软件特色

- **实时功率监控**：一屏显示瞬时功率（W）、电压（V）、电流（mA/μA）、温度（°C）
- **自动单位适配**：自动从系统获取电流单位（μA / mA），小白也能轻松上手
- **现代化 UI**：多元化主题 + 自定义壁纸 / 透明度 / 模糊效果
- **强力后台保活**：后台持续运行，状态栏实时显示充放电状态
- **灵动岛支持**：支持国产手机各类「灵动岛」及部分第三方灵动岛 App
- **充放电会话记录**：完整记录起止电量、峰值/平均功率、温度变化、结束原因等
- **功率曲线**：可视化充放电功率变化曲线
- **界面自定义**：可自由添加/调整组件
- **悬浮窗功能**：支持悬浮窗实时显示关键信息
- **校准功能**：1.8.0 新增功率校准
- **CPU 信息查看**：（温度信息需 Shizuku 权限）
- **无电池设备优化**：针对无电池设备做了专门适配
- **OPPO 系统特别优化**：针对 OPPO 系列电流单位差异进行了优化
- **最佳适配机型**：中兴、努比亚、红魔设备表现最佳

## 🛠️ 使用说明

1. 下载并安装 APK（需允许「未知来源」安装）
2. 打开应用后，系统会自动识别电流单位
3. 如功率显示异常，可在设置中手动切换 μA / mA 单位
4. 支持后台运行，配合灵动岛可实时查看功率
5. 1.8.0 版本新增校准、自定义组件、悬浮窗等功能，可在应用内探索

## ❓ 常见问题

**这是 Switch 模拟器吗？**  
不是。Yuzu.Power 只记录手机的充放电功率，和任天堂主机、游戏模拟器没有任何关系。

**支持哪些手机？**  
Android 应用。作者标注主流机型支持率 98.6%，中兴 / 努比亚 / 红魔效果最佳，OPPO 系做了电流单位适配。部分异形屏可能显示不佳。

**安装后卡在优化界面？**  
到系统「应用信息」中清除本应用数据后再打开。
