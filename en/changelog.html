Release notes

Changelog

A record of feature changes, compatibility notes and important fixes for each public Yuzu.Power release.

Yuzu.Power 3.3.0

November 14, 2026
Released

What’s new

  • Added a Connection Information card for Wi-Fi and mobile networks, including carrier, network type, frequency band and signal strength, with multi-SIM support and expandable details.
  • Added a floating network speed component showing upload and download rates separately.
  • Added Self-discipline space to suspend third-party apps for a set duration in one tap, with app exemptions and automatic restoration when the session ends, reducing distractions to help you focus.
  • Added a recovery counter showing how many times the Shizuku monitor guard successfully restored monitoring in the past 24 hours.
  • Updated the remaining discharge time prediction model for improved accuracy and lower prediction power consumption.
  • Optimized background sampling and task scheduling to reduce memory use and substantially lower standby power consumption.
  • Improved home card text fitting, stack transitions and detail expansion animations.
  • Improved component insertion and preview switching in the floating overlay editor.
  • Refined various details and fixed other issues.

Yuzu.Power 3.2.0

November 3, 2026
Released

What’s new

  • Added App freezer (Beta). Freeze, suspend, and restore apps through Shizuku, with batch operations from the freezer drawer.
  • Optimized history sampling and compressed storage to reduce storage usage over time.
  • Improved home screen card sizing, text layout, and transition animations.
  • Improved battery level and temperature curve smoothing, curve transitions, and animations when expanding charging and discharging records.
  • Improved loading of charging and discharging record details.
  • Improved the automatic calibration screen layout across different screen sizes.
  • Fixed an issue where selecting a home screen wallpaper could sometimes fail to open the crop screen.
  • Refined various details and fixed known issues.

Yuzu.Power 3.1.0

Released

Yuzu.Power 3.0.0

October 25, 2026
Released

What’s new

  • Integrated Shizuku to access additional device data after authorization.
  • Redesigned the home screen with a variety of component cards. Add, reorder, resize, and stack cards freely.
  • Redesigned the live overlay with more data and functional components. Create custom layouts and save multiple configurations to switch between. Customize the language, font, and light or dark theme; adjust background and content opacity independently; set the automatic fade level; and save separate positions for portrait and landscape.
  • Added live overlay layout sharing. Create share posters and codes, then import a layout by scanning a code or selecting an image.
  • Added the Obsidian and Ember themes, and refined the colors of existing themes.
  • Added a guided automatic calibration flow.
  • Added charging animations.
  • Added a particle starfield effect with HDR support for the automatic calibration guide and charging animation screens.
  • Added a built-in wallpaper.
  • Refined various details and fixed known issues.
