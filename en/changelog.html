Changelog

Notes below are based on GitHub Releases — features, cautions, and important fixes for each public build.

Yuzu.Power 2.0.0

16 Nov 2026
Current

What is new

  • Connection info card: Wi-Fi and mobile network details (carrier, radio type, band, signal strength), multi-SIM support, and expandable details.
  • Network speed overlay component with separate upload and download rates.
  • Focus Space: one-tap timed freeze for third-party apps, with allow-list exceptions; frozen apps auto-restore when the session ends.
  • Guardian recovery stats: successful Shizuku monitor recoveries in the last 24 hours.
  • Updated remaining-time prediction model for better accuracy and lower compute cost.
  • Background sampling and task scheduling optimized for lower memory use and much lower standby power.
  • Home card typography, stack transitions, and detail expand animations improved.
  • Overlay editor: smoother component add and preview switching.
  • Various UI polish and bug fixes.

Yuzu.Power 1.9.0

4 Nov 2026
Released

Improvements

  • Calibration algorithm refined.
  • Layout polish on selected screens.
  • Special thanks moved to About - Updates and notices.
  • "Hide background" moved under Stable running.

New

  • App Freezer (beta).
  • Power usage statistics.

Notes

  • Upgrading from 1.4.0: back up data first; after upgrade, clear app data and re-import if needed.
  • If Shizuku auth breaks after upgrading from 1.8.0, stop Shizuku and re-activate it.
  • AxManager is recommended for Shizuku authorization.
  • 1.8.0 and later require Android 12+; use 1.4.0 on older systems.

Yuzu.Power 1.8.0

31 Oct 2026
Released

What is new

  • Major app rewrite with calibration support.
  • CPU info view (temperature needs Shizuku).
  • Customizable home layout — add components that were not available before.
  • Floating overlay information features.
  • Official website updated (see About).

Notes

  • Major update: back up charge data before upgrading; clearing app data after install is recommended to avoid stutter and compatibility issues.
  • Android 12 or later required from this version onward.
