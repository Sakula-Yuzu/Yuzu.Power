Permissions

Understand how each permission is used and which access needs your approval or is granted automatically by the system.

Applies to: 3.3.0Android 8.0+

Permission overview

Yuzu.Power 3.3.0 does not request internet access, contacts, SMS, call logs, microphone or location permissions. Camera access is used only to scan overlay layout share codes. You can still import layouts from images without camera access.

Not every item requires manual approval. Foreground services, boot broadcasts, wake locks, network state, Wi-Fi state and basic phone state use normal permissions granted by the system at installation, without individual runtime prompts or Deny buttons. Notifications, camera and special access are requested as needed for your Android version and chosen features. System image and file pickers provide only content you select.

About the accessibility service

The accessibility service is an optional advanced keep-alive method and is off by default. The current implementation has these limits:

  • It is explicitly configured not to read window content;
  • It cannot perform taps, swipes or other gestures;
  • It cannot listen for keys or enable touch exploration;
  • It does not record screen text, input or used apps;
  • It receives window-change events and uses only window-state changes to trigger monitoring health recovery.

How to revoke permissions

Revoke camera, notification or overlay access in Android Settings → Apps → Yuzu.Power → Permissions / Special app access. Accessibility and battery-optimization exclusions can be disabled on their own settings pages. Revoke Shizuku access in Shizuku’s authorized-app management. Setting names vary by system.
